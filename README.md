# ShapeBit Desktop

ShapeBit Desktop is the custom Wayland desktop environment for ShapeBit OS.
It is intended to organize work around persistent activities and materials,
rather than around a taskbar full of applications.

The repository does not yet contain an implemented or verified desktop.

## Documentation

Desktop goals, interaction designs, and owning architecture are maintained in
the [ShapeBit Desktop documentation](https://shapebit.software/docs/desktop/).
